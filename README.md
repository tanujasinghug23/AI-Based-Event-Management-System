# AI-Based-Event-Management-System
This project is a simple AI-based event planner that helps users come up with ideas and plan events more easily. It takes user input and generates suggestions like themes, schedules, and basic planning details.

## Features
- AI-generated event suggestions
- Simple and clean user interface
- Save event feature using localStorage
## Tech Stack
- Next.js (React)
- JavaScript
- OpenAI API
## How to Run
git clone https://github.com/tanujasinghug23/AI-Based-Event-Management-System.git cd AI-Based-Event-Management-System npm install npm run dev Open http://localhost:3000
